# Sistema de Gestión de E-commerce en Go

Proyecto académico desarrollado en lenguaje Go.

## Objetivo

Desarrollar una aplicación de consola para gestionar el proceso básico de un
e-commerce, incluyendo catálogo de productos, carrito de compras, inventario,
promociones y pedidos.

## Estado del proyecto

Actualmente se encuentra en la etapa de configuración inicial y definición de
la estructura del sistema.

## Tecnologías

- Go
- Git
- GitHub
- Visual Studio Code

## Funcionalidades

- Catálogo
- Carrito
- Promociones
- Inventario
- Pedidos
- Pagos simulados

## Requisitos

- Go 1.22 o posterior

## Ejecución

go run ./cmd/tienda
